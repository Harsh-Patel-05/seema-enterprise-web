# Seema Enterprise

Premium **business + product catalogue + enquiry** website for Seema Enterprise.

## Important

This is **not** an e-commerce website. There is no cart, checkout, payment or customer login.

Customers can explore products, brands and categories, then submit enquiries for quotations and purchase assistance.

## Stack

- React + Vite
- React Router
- Tailwind CSS v4
- Lucide React

## Run

```bash
npm install
npm run dev
```
